# UVT — Universal Voice Translator

Закадровый перевод речи из **любого источника звука** в реальном времени.
Не расширение браузера и не скрипт под конкретный сайт: UVT слушает системное
аудио, поэтому работает с YouTube, Twitch, Netflix, Zoom, Discord, VLC,
играми, IPTV — со всем, что издаёт звук.

```text
Любое приложение → Захват системного звука → VAD → STT → Перевод (LLM)
                → TTS → Наушники / виртуальный кабель (OBS, Discord)
                                → Оверлей субтитров поверх всех окон
```

**Статус: v0.1 (каркас MVP).** Ядро конвейера работает и покрыто тестами;
захват WASAPI loopback и GUI — экспериментальные, см. [дорожную карту](#дорожная-карта).

## Возможности

- **Источник — системный звук**: любое устройство ввода, BlackHole (macOS),
  VB-Cable, monitor-источники PipeWire (Linux), WASAPI loopback (Windows).
- **VAD**: Silero (ONNX, без PyTorch), WebRTC или энергетический резерв.
- **STT**: Faster Whisper локально (автоопределение языка) или любой
  OpenAI-совместимый endpoint (OpenAI, Groq).
- **Перевод**: один движок покрывает OpenAI, DeepSeek, Grok, Groq, OpenRouter,
  **Ollama**, **LM Studio**, llama.cpp и любые OpenAI-совместимые endpoint.
  Настраиваемый системный промпт и глоссарий.
- **TTS**: Edge TTS (бесплатно, без ключа) или Kokoro (локально, ONNX).
- **Режимы**: только субтитры / закадровая озвучка; вывод в наушники или в
  виртуальный кабель — дальше OBS, Discord, Zoom.
- **Дубляж файлов и роликов по ссылке** (`uvt dub`): перевод готовится заранее,
  в готовом файле оригинальный голос приглушён и заменён переведённым точно в
  тех местах, где звучал; видео не перекодируется.
- **История**: экспорт srt / vtt / txt / json.
- **Плагины**: свои STT/переводчики/TTS/захват — один `.py`-файл в `plugins/`,
  ядро не трогается ([plugins/README.md](plugins/README.md)).
- **Полностью локальный режим**: Whisper + Ollama + Kokoro — без единого
  облачного запроса.

## Установка

Нужен Python 3.10+ (рекомендуется 3.12/3.13).

```bash
git clone <repo> && cd uvt
python3 -m venv .venv && source .venv/bin/activate
pip install -e ".[recommended]"        # ядро + Whisper + Silero VAD + Edge TTS
# дополнительно: ".[gui]" (PySide6), ".[kokoro]", ".[webrtc]", ".[windows]"
```

Проверка установки — демо-конвейер без моделей и сети:

```bash
uvt run --profile demo
```

## Настройка захвата системного звука

UVT читает звук с *устройства ввода*, поэтому системный звук нужно завернуть
в виртуальное устройство (или использовать loopback на Windows).

**macOS** — [BlackHole](https://github.com/ExistentialAudio/BlackHole):

```bash
brew install blackhole-2ch
```

В Audio MIDI Setup создайте Multi-Output Device (динамики + BlackHole), сделайте
его выходом системы, а в UVT укажите `capture.device: "BlackHole 2ch"`.

**Windows** — родной loopback, виртуальные кабели не нужны:

```yaml
capture:
  backend: wasapi-loopback   # pip install -e ".[windows]"
```

**Linux** — выберите monitor-источник PipeWire/PulseAudio из `uvt devices`.

Список устройств: `uvt devices` (виртуальные помечены 🔁).

## Запуск

```bash
uvt run --profile youtube            # EN→RU озвучка: Whisper + Ollama + Edge TTS
uvt run --profile meeting            # субтитры с минимальной задержкой для звонков
uvt run --profile cloud              # перевод через OpenAI API (ключ в OPENAI_API_KEY)
uvt run --target-lang ru --debug     # настройки по умолчанию + тайминги стадий
uvt gui                              # графический интерфейс (экспериментальный)
```

Профили лежат в [profiles/](profiles/) — это обычный YAML, полный справочник
ключей в [profiles/default.yaml](profiles/default.yaml). Свои профили можно
класть в `~/.config/uvt/profiles/`.

Для полностью локального перевода поднимите [Ollama](https://ollama.com):
`ollama pull qwen2.5:7b-instruct` — профиль youtube уже настроен на него.

### Полностью бесплатный режим (без ключей и токенов)

```bash
uvt serve -p free      # или: uvt dub <файл|ссылка> -p free
```

Профиль [free](profiles/free.yaml): Whisper локально + перевод через публичный
endpoint Google Translate (движок `google-free`, без ключа) + Edge TTS.
Качество перевода ниже GPT (буквальнее), озвучка менее живая, чем OpenAI TTS, —
но совокупная стоимость ровно ноль. Промежуточный вариант — Ollama:
GPT-уровень перевода бесплатно и локально (блок в том же профиле).

## Перевод файлов и роликов — с заменой голоса (uvt dub)

Главный режим, когда важна именно **замена** голоса: перевод готовится заранее,
затем собирается новая дорожка — оригинальная речь приглушается, поверх точно
по таймингам ложится переведённая.

Все стадии пакетные: Whisper распознаёт весь файл одним батч-проходом
(таймкоды сразу), LLM переводит пачками по 20 реплик (соседние реплики —
контекст), озвучка идёт параллельно. Самая быстрая конфигурация STT — облачный
Whisper на Groq (см. закомментированный блок в profiles/cloud.yaml).

```bash
uvt dub lecture.mp4 --profile youtube               # → lecture.dub.mkv + .srt + .json
uvt dub "https://youtube.com/watch?v=…" -p cloud    # ссылки: pip install yt-dlp
uvt dub file.mp4 --duck-db -60                      # почти полностью убрать оригинальный голос
uvt dub file.mp4 --no-original-track                # не сохранять оригинальную дорожку
```

Результат — `.mkv`: видеопоток скопирован без перекодирования, переведённая
дорожка основная, оригинальная — вторая (переключается в любом плеере).

### Кнопка в браузере (как voice-over-translation)

UX исходного референса — кнопка прямо на видеоплеере — реализуется связкой
«локальный сервер + userscript»:

```bash
pip install -e ".[server]"
uvt serve -p cloud        # http://127.0.0.1:8765
```

Затем установите [browser/uvt.user.js](browser/uvt.user.js) в Tampermonkey
(инструкция: [browser/README.md](browser/README.md)). На любом `<video>`
появится кнопка **UVT**: нажатие отправляет ролик локальному серверу, тот
готовит переведённую дорожку, и скрипт проигрывает её синхронно с видео,
приглушив оригинал. Пауза/перемотка/скорость синхронизируются, повторное
нажатие выключает перевод.

### Замена голоса при живом просмотре сайтов

Два пути:

1. **Идеальная замена** — прогнать ролик через `uvt dub <ссылка>` и смотреть
   готовый файл: тайминги точные, оригинальная речь приглушена.
2. **Прямо во время просмотра** — выбрать выходом системы только «BlackHole 2ch»
   (без Multi-Output Device): оригинал становится неслышен, UVT выводит в
   динамики только перевод. Минус: пропадает и фоновая музыка; passthrough-микшер,
   который вернёт фон приглушённым, запланирован в v1.5. Если фон важен —
   используйте Multi-Output (режим «закадровый перевод поверх тихого оригинала»).

## Задержка

Пресеты (ТЗ §11): `ultra` (пауза-отсечка ~300 мс), `balanced` (~500 мс),
`accuracy` (~800 мс). Итоговая задержка = пауза VAD + STT + LLM + первые байты
TTS; медианы по стадиям видны с флагом `--debug` и в GUI. Помните: закадровый
перевод принципиально ждёт конца реплики — «мгновенного» перевода незаконченной
фразы не существует, есть только компромисс задержка/точность.

## Архитектура

Каждый этап — независимый сервис на asyncio, обмен только через шину сообщений
(очереди с вытеснением). Подробности, бюджет задержек и Plugin API —
в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

```text
CaptureService → VADService → STTService → TranslationService ─┬→ TTSService → OutputService
                                                                ├→ OverlayService
                                                                └→ HistoryService
```

  видео в GUI, двухканальный режим dual.
- **v2.0** — клонирование голоса (XTTS/Fish Speech), диаризация спикеров,
  память перевода, адаптивное шумоподавление.
