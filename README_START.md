# UVT — как запустить и пользоваться

Рабочая папка: **`/Users/teotim/Documents/голос`**.

## Открыть интерфейс

Дважды нажмите **[Запустить UVT.command](<Запустить UVT.command>)** в Finder. Откроются терминал и панель в браузере. Терминал оставьте открытым: в нём работает сервер.

То же самое из терминала:

```bash
cd "/Users/teotim/Documents/голос"
bash scripts/serve-personal.sh --open-browser
```

**Все три режима запускаются сразу одной командой:**

| Режим | Интерфейс | Для чего |
| --- | --- | --- |
| **Local / Free** | [Панель и настройки](http://127.0.0.1:8765/) · [Студия](http://127.0.0.1:8765/workspace) | Перевод локальными моделями на Mac |
| **GPT** | [Студия GPT](http://127.0.0.1:8766/workspace) | Распознавание, перевод и голос OpenAI |
| **ElevenLabs** | [Студия ElevenLabs](http://127.0.0.1:8767/workspace) | OpenAI для текста, ElevenLabs для голоса |

Это три маршрута обработки; все локальные модели не загружаются в память одновременно. Для облачных режимов используются ключи из существующего `.env`: `OPENAI_API_KEY`, а для ElevenLabs ещё `ELEVENLABS_API_KEY`.

Если интерфейс просит токен, укажите `UVT_API_TOKEN` из своего `.env`. Не вставляйте туда ключ OpenAI или ElevenLabs.

## Выбрать новые модели

В **настройках Free** выберите профиль и сохраните настройки. В студии также можно выбрать профиль для конкретного видео.

| Профиль в списке | Модели | Когда выбирать |
| --- | --- | --- |
| **Hy-MT2 · быстрый + Piper** (`local-hymt`) | Parakeet → Hy-MT2 1.8B → Piper | Начните с него для быстрого локального перевода на русский или украинский |
| **Hy-MT2 + MOSS · живые голоса** (`local-moss`) | Parakeet → Hy-MT2 → MOSS на CPU | Русская озвучка: Adam/Nathan (мужские), Ava/Bella (женские) или свой образец голоса. Украинского голоса у MOSS нет |
| **Nemotron + Hy-MT2 + Piper** (`local-nemotron`) | Nemotron 3.5 → Hy-MT2 → Piper | Попробовать другое распознавание; русский и украинский перевод озвучивает Piper |
| **Сбалансированный** (`local-balanced`) | Parakeet → TranslateGemma → Piper | Прежний основной профиль для сравнения качества |

Новые модели скачаны и проверены отдельно на этом Mac; полные `local-moss` и `local-nemotron` также завершили короткий нейтральный дубляж EN→RU. Это экспериментальные профили. Hy-MT2 иногда допускает грамматические ошибки; Nemotron ещё нужно сравнить с Parakeet на русской/украинской речи. **«Живые голоса · медленно»** (`local-natural`, Demucs + F5) по-прежнему значительно тяжелее.

Обычный запуск не скачивает веса. Проверить наличие новых моделей без сети:

```bash
source .venv/bin/activate
uvt setup-mac-local --preset hymt --check
uvt setup-mac-local --preset moss --check
uvt setup-mac-local --preset nemotron --check
```

Если нужный набор отсутствует, выполните ту же команду **без `--check`**. Новые веса лежат в `.models/` внутри проекта. При установке с нуля дополнительные зависимости ставятся командой `pip install -e ".[mac-local,local-next]"`; на уже подготовленном Mac повторять её при запуске не нужно.

## Выбрать любимые мужской и женский голоса

1. Откройте [панель настроек](http://127.0.0.1:8765/), выберите **Free**, **GPT** или **ElevenLabs**, затем язык перевода. Для Free также выберите локальный профиль.
2. В полях **«Мужской голос»** и **«Женский голос»** выберите понравившиеся тембры. У каждого есть своя кнопка прослушивания.
3. Оставьте **«Тембр / пол голоса» → «Авто по спикеру»**, чтобы в диалоге использовались оба голоса, и нажмите **«Сохранить»**.

Пара запоминается отдельно для движка и языка: выбор для русского Piper не заменяет украинский Piper или MOSS. Необязательный **«Один голос для всех»** имеет приоритет над парой; для диалогов оставьте его автоматическим.

В **F5 и MOSS** можно раскрыть **«Добавить свой образец голоса»**, загрузить 3–30 секунд чистой речи одного человека и вписать точный текст записи. После сохранения выберите образец в нужной роли. Пустой выбор сохраняет клонирование голоса из оригинала, когда исходный образец доступен.

Прослушивание выполняет настоящую озвучку. **Пробы GPT и ElevenLabs расходуют квоту провайдера**; локальные пробы запускаются на Mac. [Подробнее о голосах, образцах и точности определения говорящего](docs/VOICE_SELECTION.md).

## Перевести видео и смотреть результат

1. Откройте [локальную студию](http://127.0.0.1:8765/workspace), добавьте ссылку или перетащите сохранённый видеофайл.
2. Выберите язык, профиль и голос, затем запустите перевод.
3. После готовности дорожки студия подготавливает видео. Если у старого задания доступна только дорожка, нажмите **«Подготовить видео»**: распознавать и переводить заново не нужно.
4. Смотрите видео в студии. Ползунки **оригинала** и **перевода** регулируются независимо.
5. Скачайте **MP4 с переводом**. Чтобы сохранить выбранную громкость, нажмите **«Сохранить видео с этой громкостью»** — меняется сборка звука, повторной озвучки нет.

Также доступны оригинальное видео, M4A, SRT, VTT, текст и JSON. Для загружаемого файла можно дополнительно собрать MKV с двумя аудиодорожками. Готовые задания сохраняются между перезапусками; срок хранения кэша — 7 дней. Сохраните нужные результаты себе.

Лимит исходника: **2 ГБ / 90 минут**. При отдельном получении видео по ссылке выбирается качество до 720p; уже полученный исходник меньшего разрешения не увеличивается искусственно. [Подробнее о видео и громкости](docs/VIDEO_RESULTS.md).

## Видео в Chrome

Установите Tampermonkey, затем [UVT userscript](http://127.0.0.1:8765/workspace/userscript.user.js) или [локальный файл](browser/uvt.user.js). Перезагрузите вкладку с видео и выберите Free / GPT / ElevenLabs. Сервер UVT должен работать всё время перевода. Версия **0.18.2** размещает управление на основном плеере; карточки рекомендаций, мини-превью и фоновые видео отфильтровываются. После обновления скрипта перезагрузите страницу.

## Живой диалог и звонки

Откройте **[Запустить диалог.command](<Запустить диалог.command>)**. В настольном интерфейсе выберите профиль, вход звука и наушники, затем **«Запустить Live перевод»**. Для своей речи подходит микрофон, для звука звонка — настроенный BlackHole/виртуальный вход.

**«Диалог на Mac»** (`local-dialogue`) использует Parakeet → NLLB → Piper и короткие завершённые фразы. Для сравнения новых моделей доступны `local-hymt`, `local-moss`, `local-nemotron`; открыть выбранный профиль можно командой `uvt gui -p local-hymt`. MOSS используется для русского перевода, для украинского выбирайте Piper.

Модели готовятся перед захватом звука. Полная задержка разговора ещё не измерена: быстрый отдельный STT или TTS не гарантирует такую же задержку звонка. Chrome и перевод ссылок пока готовят видео пакетно. [Измерения и границы живого режима](docs/LIVE_DIALOGUE_M4.md).

## Остановить, обновить, исправить ошибку

В терминале UVT нажмите **Ctrl+C** и дождитесь приглашения ввода. Затем снова откройте **«Запустить UVT.command»**. После обновления кода требуется перезапуск процесса; обновления страницы недостаточно. После изменения userscript обновите его в Tampermonkey и перезагрузите вкладку с видео.

- **Address already in use / порт уже занят.** Откройте уже работающий UVT по адресу из таблицы выше. Для нового запуска остановите прежний UVT через **Ctrl+C** в его терминале и повторите `uvt serve-personal`.
- **ElevenLabs: превью играет, а перевод выдаёт HTTP 402.** Превью и генерация имеют разные ограничения. На Free API голос из Voice Library может быть недоступен при положительном балансе. Без пользовательской пары UVT использует стандартные **Sarah / Adam**. Для выбранной пары проверьте доступность обоих голосов через кнопки прослушивания: библиотечный голос может требовать платный тариф. Явный выбор не подменяется автоматически.
- **`libtorchcodec`, `libx265` или `PYTHONHASHSEED` в F5.** Запускайте обновлённый проект через его launcher: он готовит окружение до старта Python. Скачивать заново все модели или устанавливать все перечисленные версии FFmpeg не требуется.
- **Модель не готова.** Запустите соответствующий `setup-mac-local --preset … --check`; при отсутствии файлов — установку без `--check`.
- **Ссылка не загрузилась.** Попробуйте перевод через userscript на открытой странице или добавьте сохранённый локальный файл. Студия показывает причину получения исходника отдельно от ошибок моделей.
