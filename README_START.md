# UVT — как запустить и пользоваться

Рабочая папка проекта: **`/Users/teotim/Documents/голос`**.

## Запуск двойным щелчком на Mac

Откройте папку проекта в Finder и дважды нажмите **[Запустить UVT.command](<Запустить UVT.command>)**.

Откроется терминал, запустятся все три режима перевода и появится панель в браузере. Терминал оставьте открытым — в нём работает сервер.

То же самое из терминала:

```bash
cd "/Users/teotim/Documents/голос"
bash scripts/serve-personal.sh --open-browser
```

Окружение проекта уже подготовлено. При обычном запуске не нужно заново устанавливать программу или скачивать модели.

## Где интерфейс и три режима

**Общая панель и настройки:** [http://127.0.0.1:8765/](http://127.0.0.1:8765/).

| Режим | Открыть перевод файлов и ссылок | Что используется |
| --- | --- | --- |
| **Local / Free** | [Локальная студия](http://127.0.0.1:8765/workspace) | Модели на Mac. Для M4 / 16 ГБ выбирайте **«Сбалансированный»** |
| **GPT** | [Студия GPT](http://127.0.0.1:8766/workspace) | Распознавание, перевод и голос через OpenAI |
| **ElevenLabs** | [Студия ElevenLabs](http://127.0.0.1:8767/workspace) | Распознавание и перевод через OpenAI, голос через ElevenLabs |

**Все три режима запускаются одной командой.** Отдельно запускать каждый не нужно. Это три варианта обработки; несколько тяжёлых локальных моделей не требуется одновременно держать в памяти.

Облачные режимы расходуют квоту провайдеров. Для GPT в существующем `.env` нужен `OPENAI_API_KEY`, для ElevenLabs — он же и `ELEVENLABS_API_KEY`. Локальный режим обходится без этих ключей. Если панель просит токен доступа, используйте значение `UVT_API_TOKEN` из `.env` — это отдельный токен самой панели.

Адреса выше указаны для обычных портов проекта. Если вы меняли порты, используйте адреса, которые напечатаны при запуске в терминале.

## Перевести скачанное видео

1. Откройте [локальную студию](http://127.0.0.1:8765/workspace) или нужный облачный режим из таблицы.
2. Перетащите файл либо выберите вкладку **«Ссылка»** и вставьте адрес видео.
3. При необходимости выберите язык и голос в настройках перевода.
4. Нажмите **«Начать перевод»**. Этапы и кнопка отмены появятся ниже.
5. Скачайте озвучку, субтитры или MKV с переводом. Для сохранения MKV отметьте **«Сохранить также видео с переводом»** перед запуском.

Файлы — до **2 ГБ и 90 минут**. Сохраняйте нужные результаты до перезапуска сервера: список задач не сохраняется между запусками.

Для скорости на M4 / 16 ГБ используйте **`local-balanced` / «Сбалансированный»**. **`local-natural` / «Живые голоса»** отделяет речь и клонирует голос; обработка может идти дольше самого видео. Выбор, сохранённый в панели, действует для следующих задач. Отдельные настройки на видео могут его переопределять.

## Перевод прямо в Chrome

1. Установите Tampermonkey из магазина расширений Chrome.
2. При запущенном UVT откройте [установку userscript](http://127.0.0.1:8765/workspace/userscript.user.js) и подтвердите установку или обновление в Tampermonkey. Если установщик не появился, создайте новый скрипт в Tampermonkey и вставьте содержимое [browser/uvt.user.js](browser/uvt.user.js).
3. Перезагрузите вкладку с видео. На плеере появятся кнопки **Free / GPT / ElevenLabs**.

Сервер UVT должен работать всё время перевода. После обновления userscript обязательно перезагрузите вкладку с видео.

## Остановить или перезапустить

В терминале, где работает UVT, нажмите **Ctrl+C** и дождитесь возвращения приглашения ввода. Так останавливаются все три режима. Если идёт вычисление, завершение может дождаться текущего фрагмента.

Для перезапуска снова откройте **«Запустить UVT.command»**. После изменения кода нужен перезапуск сервера, после изменения userscript — ещё и его обновление в Tampermonkey.

## Если не запускается

- **Порт уже занят:** найдите терминал с ранее запущенным UVT и остановите его через Ctrl+C. Затем запустите проект один раз.
- **Панель не открылась автоматически:** откройте [127.0.0.1:8765](http://127.0.0.1:8765/) вручную. Сообщение об ошибке ищите в терминале запуска.
- **Ссылка долго подключается:** в студии видно время ожидания источника. Если сайт не начал передачу за две минуты, появится ошибка с вариантами открыть видео через UVT в Chrome или загрузить локальный файл. Кнопка на плеере в Chrome может передать адрес уже открытого медиапотока; одно поле ссылки в студии передаёт только страницу.
- **Облачный режим сообщает об ошибке ключа или лимита:** проверьте соответствующий ключ и баланс провайдера. Локальный режим от облачных ключей не зависит.
- **Не хватает локальных моделей:** из папки проекта выполните команды ниже. Первая только проверяет кэш; вторая скачивает недостающие модели и нужна лишь при их отсутствии.

```bash
source .venv/bin/activate
uvt setup-mac-local --preset balanced --check
# Только если проверка сообщила об отсутствующих моделях:
uvt setup-mac-local --preset balanced
```

## Другие способы работы

Для отдельного desktop-окна после активации окружения используйте `uvt gui -p local-balanced` (нужен установленный компонент GUI). Веб-студия выше работает без него.

Для звонков есть экспериментальные локальные субтитры `uvt gui -p local-meeting`. Сначала нужен настроенный аудиовход BlackHole; это не автоматический захват звонка из браузера.
