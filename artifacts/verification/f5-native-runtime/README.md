# F5 / TorchCodec: проверка исправления

Дата: 2026-09-06. Проект: `/Users/teotim/Documents/голос`.

## Причина и исправление

TorchCodec загружает FFmpeg внутри Python. На этом Mac FFmpeg 8.1.2 зависит от `libx265.216.dylib`, которая остаётся в Homebrew Cellar 4.2, тогда как `opt/x265` указывает на 4.3 с другим ABI. Уже существующая проверенная обёртка задавала путь только для отдельных команд. Позднее изменение `os.environ` внутри UVT исправляло дочерний FFmpeg, но не нативный загрузчик текущего Python.

Теперь обычный файл запуска подключает библиотеку до Python. Прямой CLI выполняет однократный `execve` при необходимости исправления, сохраняя аргументы и окружение. Системные библиотеки, Homebrew-ссылки и зависимости не менялись.

F5 также проверяет настоящий `torchaudio.load` на коротком PCM WAV до обработки видео. После исправления декодера реальный синтез выявил ещё один дефект upstream: случайный seed до `sys.maxsize` экспортируется в `PYTHONHASHSEED`, хотя дочерний Python принимает только 32-битное значение. UVT теперь передаёт корректный seed.

## Проверки

- Без раннего окружения: `ensure_media_runtime()` успешно исправляет дочерние медиакоманды, но `torchaudio.load` падает на отсутствующей `libx265.216.dylib`.
- С окружением до Python: тот же WAV читается, 1 канал / 2400 отсчётов / 24000 Гц.
- Прямой `python -m uvt dub` с несуществующим тестовым входом: один автоматический перезапуск, затем ожидаемая ошибка входного файла; циклического запуска нет.
- `bash scripts/serve-personal.sh --help`: исправление окружения и передача параметров работают, порты не открывались.
- Полный набор: **380 passed in 9.88s**; проверены ошибки раннего декодера, повтор после сбоя, сохранение аргументов/окружения, seed и реальный запуск дочернего Python.
- Реальная F5 Russian: **5.013 с** звука / **24000 Гц**, конечные ненулевые отсчёты, `device=mps`, `nfe_step=16`. Декодер **1.677 с**, загрузка **11.75 с**, синтез **42.301 с**.
- В итоговом журнале нет ошибок `libtorchcodec` и `PYTHONHASHSEED`. PyAV и системный FFmpeg выводят предупреждения о дублирующихся Objective-C классах; этот синтез завершился с кодом 0. Переустановка медиабиблиотек в эту правку не входит.

Использованы только локально кэшированные модели (`HF_HUB_OFFLINE=1`, `TRANSFORMERS_OFFLINE=1`) и существующий нейтральный образец о рабочей встрече. Видео пользователя не использовалось. Качество на слух и перевод полного видео не проверялись. Эти цифры подтверждают работоспособность, но не делают F5 быстрым режимом для M4 / 16 ГБ.
