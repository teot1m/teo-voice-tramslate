## Пределы проверки

Это функциональная проверка, не аппаратный benchmark звонка. Пользовательская задача `1350f14f8e2a` продолжала озвучку F5 (при последней проверке статус running/synthesize); процесс не останавливался. Чтобы не исказить скорость и не конкурировать за 16 ГБ, новые тяжёлые модели и реальный звонок одновременно с ним не запускались. Новых весов и пакетов не установлено.

Исследование новых моделей, первоисточники и план измерения находятся в `docs/LIVE_DIALOGUE_M4.md`. Hy-MT2, MOSS и Nemotron пока кандидаты, а не активные backend этого профиля. Поле `target_delay_s=0.25` — смещение планировщика, не измеренная задержка ASR→MT→TTS.

## Применение и откат

После окончания тяжёлой задачи открыть `Запустить диалог.command`, выбрать вход/выход и нажать `Запустить Live перевод`. Уже работающий процесс не подхватывает изменённый код. Для отката отменить только изменения этого live-этапа и использовать прежние профили; фиксы F5/FFmpeg из предыдущего этапа сохраняются. Коммиты, push, новые проекты и новые серверы при проверке не создавались.
