RTF — время генерации / длительность звука. RSS и выделения MLX измеряют разное; эта таблица не даёт общего пика памяти профиля. Время текущей фразы Hy-MT2 — один вызов, не медиана или p95.

Ограничения качества: Hy-MT2 допускала «не опаздьте» и украинское «синім чашкою». Nemotron ошибся на английском «budget and». Полноценные оценки грамматики перевода, RU/UK распознавания, естественности и сходства голоса не выполнялись. В выбранной ONNX-модели MOSS 19 языков, украинский не поддерживается.

## Причина ElevenLabs 402 и исправление

На текущем ключе и `eleven_turbo_v2_5` прежний автоматический женский ID `21m00Tcm4TlvDq8ikWAM` разрешился в Janet из Voice Library. На слово «Проверка.» API ответил **402 / payment_required**: бесплатным пользователям недоступны library-голоса через API. Это не означает отсутствие кредитов.

На том же ключе стандартный Adam (`ErXwobaYiN019PkySvjV`) ответил **HTTP 200**; стандартная Sarah (`EXAVITQu4vr4xnSDxMaL`) также ответила **HTTP 200**, 14 254 байта MP3. Auto теперь Sarah/Adam; явно выбранные и заданные окружением голоса сохраняют приоритет. Превью не проверяет право на генерацию.

[Диагностика](eleven-diagnosis.json) · [старые голоса: 402/200](eleven-tts-probe.json) · [Sarah: 200](eleven-sarah-probe.json). Ключи не записаны. Чтение подписки этому ключу недоступно из-за отсутствующего разрешения `user_read`; это не препятствовало успешному синтезу. Тариф и права ключа не менялись.
