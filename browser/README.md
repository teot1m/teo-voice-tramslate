# Кнопка UVT в браузере

Аналог [voice-over-translation](https://github.com/ilyhalight/voice-over-translation),
но перевод делает ваш локальный UVT (Whisper + ваш LLM + TTS), а не облако Яндекса.

Как это работает: userscript вешает кнопку **UVT** на любой `<video>` на
странице. По нажатию адрес страницы (и прямая ссылка на поток, если есть)
уходит на локальный сервер `uvt serve`; тот скачивает звук, готовит
переведённую дорожку и отдаёт её обратно. Скрипт проигрывает её синхронно с
видео, приглушив оригинал — голос «заменён», музыка и эффекты остаются тихим
фоном. Пауза, перемотка и скорость видео синхронизируются автоматически.

## Установка (один раз)

1. Расширение [Tampermonkey](https://www.tampermonkey.net/) в Chrome/Firefox/Edge.
2. Tampermonkey → «Создать новый скрипт» → вставьте содержимое
   [uvt.user.js](uvt.user.js) → Сохранить (⌘S).
3. Зависимость сервера: `pip install -e ".[server]"` (в venv проекта).

## Использование

```bash
cd ~/Documents/голос && source .venv/bin/activate
uvt serve -p cloud          # сервер слушает http://127.0.0.1:8765
```

Откройте страницу с видео → на плеере появится кнопка **UVT** → нажмите.
Кнопка покажет прогресс (⏳ %), после готовности перевод зазвучит поверх
приглушённого оригинала. Повторное нажатие выключает перевод.

Настройки — константы в начале скрипта: `TARGET_LANG` (язык перевода),
`DUCK_VOLUME` (громкость оригинала), `SERVER` (адрес сервера).

## Ограничения v0.1

- Перевод готовится заранее целиком: для часового видео на CPU это минуты.
  Кнопку можно нажать и продолжать смотреть — перевод включится, когда готов.
- Сайты с DRM (Netflix и т.п.) не поддерживаются: поток зашифрован.
- Для видео, отдаваемых через MSE/blob (YouTube и др.), сервер качает ролик
  сам через yt-dlp — работает на всех сайтах, которые yt-dlp знает.
- Сервер без авторизации, слушает только 127.0.0.1 — любые локальные
  программы могут к нему обращаться. Токен доступа появится в v1.5.
