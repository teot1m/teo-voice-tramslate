# Видео в студии UVT

После перевода откройте результат в **Студии → Последние переводы**. Для видео появится встроенный плеер с двумя регуляторами:

- **Оригинальный звук** — речь, музыка и фон исходного ролика.
- **Перевод** — отдельная переведённая речь.

Пауза, перемотка и изменение скорости управляют обеими дорожками. По умолчанию оригинал звучит на 15%, перевод — на 100%. Ползунки изменяют текущий просмотр. Чтобы сохранить видео с этими уровнями, нажмите **«Сохранить видео с этой громкостью»** и дождитесь готовности ссылки **«Видео с переводом · MP4»**. Повторное распознавание, перевод и озвучка при этом не запускаются.

## Что можно скачать

| Кнопка | Содержимое |
|---|---|
| Оригинальное видео | Сохранённый исходный видеофайл без изменения его содержимого |
| Видео с переводом · MP4 | Видеоряд и одна смешанная звуковая дорожка с выбранными уровнями оригинала и перевода |
| Озвучка · M4A | Отдельный перевод для новых видеозаданий |
| SRT / VTT / TXT / JSON | Субтитры, текст и данные перевода |
| Две дорожки · MKV | Дополнительный экспорт при загрузке видеофайла с соответствующей опцией; перевод и оригинальная дорожка выбираются во внешнем плеере |

Для загруженных аудиофайлов по-прежнему доступен звуковой результат. Видеоряд из аудиофайла не создаётся.

## Если перевод уже готов, а видео ещё нет

Нажмите **«Подготовить видео»**. Студия добавит исходный видеоряд к готовому переводу. Если при получении звука уже был скачан полноценный видеофайл, он используется повторно. Иначе студия попробует получить видео из сохранённой ссылки. Подготовку видео можно остановить отдельно — готовый перевод останется доступен.

В старых заданиях исходный звук иногда уже смешан с переводом. Для таких результатов отдельный регулятор оригинала отключён и показано пояснение. Полностью независимые уровни доступны в новых видеозаданиях.

Прямая ссылка на результат: `http://127.0.0.1:8765/workspace?job=идентификатор`. Для защищённого сервера сначала введите обычный токен студии. Ссылка не заменяет проверку доступа.

## Хранение и качество

Готовые задания сохраняют историю и результат после перезапуска. Файлы кэша старше 7 дней удаляются при следующем запуске. Скачайте важные результаты для постоянного хранения.

«Оригинальное видео» означает тот видеофайл, который удалось получить для этого задания. Разрешение показывается под плеером. Уже скачанный ролик 240p остаётся 240p; увеличение разрешения не имитируется. При дополнительном получении видео по ссылке предпочитается формат до 720p с ограничением 2 ГБ и 90 минут. Сохранённый локальный видеофайл сохраняет своё исходное разрешение.

Для просмотра и MP4-экспорта H.264 копируется без изменения видеоряда. Другие видеокодеки один раз преобразуются в H.264; оригинальный файл сохраняется отдельно. Звуковая дорожка MP4 — AAC. Подготовка идёт по одному видео, в очереди допускается до 8 заданий. Требуемое место на диске проверяется перед началом.
