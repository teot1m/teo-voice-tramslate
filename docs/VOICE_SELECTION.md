# Голоса для озвучки

Откройте [настройки UVT](http://127.0.0.1:8765/), выберите маршрут **Free / GPT / ElevenLabs** и язык перевода. В Free выбор локального профиля определяет движок озвучки. Список голосов зависит от этого движка, языка и установленных моделей.

## Пара голосов для диалога

Выберите **«Мужской голос»** и **«Женский голос»**, прослушайте каждый и нажмите **«Сохранить»**. Это роли в переводе: для каждой можно выбрать любой доступный тембр, который вам нравится.

В поле **«Тембр / пол голоса»** оставьте **«Авто по спикеру»**. UVT постарается закрепить роль за говорящим и использовать выбранную пару. Если нужен один тембр на весь ролик, выберите его в **«Один голос для всех (необязательно)»** — этот выбор имеет приоритет. В настройках отдельного видео явный выбор также переопределяет общий.

Пары сохраняются отдельно для движка и целевого языка. Например, профили с Piper используют одну пару для русского и другую для украинского; переключение на MOSS сохраняет его собственный выбор. Возврат к прежнему языку возвращает сохранённую пару.

| Движок | Откуда берутся голоса |
| --- | --- |
| Piper | Установленные модели голоса для выбранного языка |
| MOSS | Встроенные Adam/Nathan (мужские), Ava/Bella (женские) и сохранённые собственные образцы; украинский язык текущая модель не поддерживает |
| F5 | Сохранённые образцы или голос говорящего из исходного видео |
| OpenAI | Голоса, совместимые с выбранной TTS-моделью |
| ElevenLabs | Голоса аккаунта и стандартные голоса; доступ через API зависит от тарифа и разрешений ключа |

Для профилей с Edge/Kokoro пары также передаются движку. Голос должен поддерживаться конкретной моделью и языком; сам выбор пары не устанавливает новый движок.

## Прослушать перед переводом

У каждой роли есть отдельная кнопка **«Послушать мужской» / «Послушать женский»**. Текст можно изменить в **«Проба озвучки»** — например, проверить вопрос, имя и длинную фразу. Кнопки озвучивают текущий выбор формы; для следующих видео его нужно сохранить.

Это настоящая генерация речи. Пробы **GPT и ElevenLabs расходуют их квоту**, локальные пробы используют Mac и при первом запуске могут ждать загрузки модели. Демонстрационный файл голоса на сайте провайдера не проверяет доступность синтеза через API. В частности, положительный баланс ElevenLabs Free не открывает библиотечные голоса, для которых нужен платный тариф.

## Добавить свой голос в F5 или MOSS

1. В Free выберите профиль с **F5** или **MOSS** и нужный язык перевода.
2. Раскройте **«Добавить свой образец голоса»**. Укажите понятное название и роль, загрузите аудио одного говорящего.
3. Впишите точный текст, который слышен на записи, и нажмите **«Сохранить образец»**.
4. Выберите появившийся образец в мужской или женской роли, прослушайте и сохраните настройки.

Принимается аудио **от 3 до 30 секунд, до 20 МБ**, с текстом до 2000 символов. Лучше начать с 6–10 секунд разборчивой речи без музыки, эха и другого говорящего. В библиотеке может быть до **100 образцов**. Для второго голоса повторите загрузку.

Выбранный образец заменяет автоматическое клонирование для соответствующей роли. **«Из оригинала / автоматически»** оставляет исходное поведение: F5 берёт образец говорящего из видео; MOSS использует исходный образец, а при его отсутствии — встроенный голос. Чтобы отдельно прослушать F5 без видео, сначала выберите сохранённый образец.

Библиотека хранится локально: `~/.local/share/uvt/voice-references`. Другую папку можно задать переменной `UVT_VOICE_LIBRARY_DIR` перед запуском UVT. Подготовленные аудиофайлы и текст доступны только владельцу файлов; загрузка образца для F5/MOSS не отправляет его облачному провайдеру. Новые образцы не требуют переобучения или отдельной копии модели.

## Интонация и выбор роли

Высота тона помогает выбрать тембр, но не устанавливает пол или личность человека. Шёпот, музыка, повышенная интонация и похожие голоса могут давать неоднозначные признаки. При слабых данных UVT сохраняет роль по контексту или использует резервный выбор; при известном составе диалога ручной выбор надёжнее автоматики.

Исправлены завышение F0 и зависимость разделения от согласных в отдельной фразе. На нейтральной записи одного синтетического голоса длиной 13,97 с раньше первая фраза выделялась во второго спикера, теперь все пять фраз остаются одним спикером. Результат повторён с таймингами Nemotron и Parakeet. Это проверка устойчивости, а не оценка точности определения пола. [Измерения до/после](../artifacts/verification/voice-selection/speaker-stability.json).

Для перевода файлов Hy-MT2, MLX-chat и OpenAI получают соседние реплики до и после текущей пачки. По умолчанию берутся до трёх реплик с каждой стороны, общий предел — 2400 символов; модель переводит текущую пачку, а соседние фразы служат подсказкой для смысла и обращений. Контекст сохраняется и в совместимом резервном маршруте. В профиле это `translation.file_context_lines` (0–6; 0 отключает контекст). NLLB и TranslateGemma пока сохраняют прежний перевод отдельных фраз. В живом режиме доступны только уже прозвучавшие реплики.

Выбор другого голоса меняет звучание, но сам по себе не исправляет ошибки перевода и не гарантирует исходную эмоцию. Автоматический перенос эмоции оригинала пока не реализован. Piper подходит для скорости; MOSS и F5 позволяют использовать образец тембра. F5 на M4 остаётся существенно тяжелее. Оценивать естественность лучше на нескольких репликах, включая вопросы, паузы и эмоциональные фразы.

## Когда применяются изменения

Сохранённые настройки действуют для следующих переводов; уже готовая дорожка не переозвучивается автоматически. После обновления исходников требуется штатный перезапуск UVT. Работающий перевод сначала завершите или отмените в интерфейсе. Userscript обновляется отдельно через Tampermonkey.

Текущий userscript **0.18.2** закрепляет управление за основным плеером и отфильтровывает карточки рекомендаций и мини-превью. Для выбора проверены 29 нейтральных DOM-сценариев в настоящем Chrome, включая динамическую замену плеера, iframe и полноэкранный режим. Это не гарантирует совместимость с любым будущим изменением сайта.
