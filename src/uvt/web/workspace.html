Субтитры для разговора

Экспериментальный локальный режим для Zoom, Meet и других звонков. Работает через захват системного звука на Mac.

  1. Подготовьте звук

    Установите BlackHole 2ch ↗. В «Настройке Audio-MIDI» создайте многовыходное устройство с вашими наушниками и BlackHole.

  2. Выберите устройство для звонка

    Направьте звук собеседников в это многовыходное устройство. В настройках захвата UVT выберите BlackHole 2ch. Используйте наушники, чтобы избежать эха.

  3. Запустите локальные субтитры

    Для английской речи с переводом на русский:

    uvt run -p local-meeting --source-lang en

    Сначала подготовьте локальные модели. Устройство захвата можно выбрать в профиле или графическом интерфейсе UVT.

Эта страница не слушает микрофон и не захватывает звонок. Команда выше выводит перевод в терминал. Для отдельного окна запустите uvt gui -p local-meeting. Задержка зависит от речи и нагрузки Mac.
